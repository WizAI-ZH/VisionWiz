## VisionWiz 1.8.1

### 中文

- 修复认证/验证通过后因 GitHub 匿名 API 403 限流、网络超时或临时错误而跳过自动更新弹窗的问题。查询失败会尝试 GitHub 官方公开 Release 页面，获取最新正式版本和 Windows 安装包链接。
- 如果两个查询渠道都暂时失败，自动在 15 秒、45 秒、120 秒后有限重试；正常情况下每次启动只提示一次更新。
- 对备用渠道返回的仓库、版本号、安装包链接进行严格校验，避免错误来源和错误版本。
- 已通过模拟限流、重试去重、官方网站在线查询及保护编译测试；真实安装版与威智板设备验证联动仍待进一步验收。

### English

- Fixed a missing automatic update prompt after authentication when the anonymous GitHub API hits its HTTP 403 rate limit, times out, or becomes temporarily unavailable. The updater falls back to the official public GitHub Release page to resolve the latest stable version and Windows installer.
- If both routes are temporarily unavailable, checks retry after 15, 45, and 120 seconds; a successful check prompts only once per app session.
- Fallback resolution validates the official repository, stable version tag, and version-matched Windows Setup download link.
- Validated rate-limit simulation, bounded retry/deduplication, live public Release lookup, and protected compilation. Installed-app testing with actual VESIBIT authentication remains pending.
